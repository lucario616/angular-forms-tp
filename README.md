# TP Angular Forms

Resolución de las dos consignas de Angular Forms:

1. Formulario de registro con `FormBuilder`, `Validators.required`, `FormGroup` anidado, `(ngSubmit)` y `patchValue()`.
2. Formulario dinámico de pasatiempos con `FormArray`, getter, `push()` y `@for`.

## Ejecutar

Requisitos: Node.js y npm.

```bash
npm install
npm start
```

Luego abrir:

```text
http://localhost:4200
```

## Estructura principal

```text
src/app/registro/
src/app/pasatiempos/
```

El envío del formulario de registro imprime su valor en la consola del navegador.
